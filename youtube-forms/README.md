# youtube-forms — Playwright 입국신고서/비자 튜토리얼 녹화기

브라우저가 **직접 신청서를 작성하는 모습**을 녹화합니다. 말로 설명하는 대신
작성 칸을 하이라이트하고, 실수하기 쉬운 곳에 경고 말풍선을 띄우고,
"보이는 대로 따라만 하세요"를 화면에 계속 보여줍니다.

```
youtube-forms/
├─ record.js          # 실행: node record.js mdac [--lang ko|en] [--target mock|live] [--speed 1]
├─ lib/recorder.js    # Playwright 구동 + 녹화 + mp4 변환
├─ lib/overlay.js     # 페이지에 주입되는 오버레이 (단계 배지, 하이라이트, 말풍선, 타이틀 카드, 커서)
├─ forms/mdac.js      # 서식 1개 = 파일 1개 (URL, 선택자, 샘플 데이터, 단계별 설명/실수)
├─ mock/mdac-form.html# 연습용 로컬 폼 (실제 사이트와 항목 구성만 같음, 제출 안 됨)
└─ out/               # 결과물 (git 제외): <form>-<target>-<lang>.mp4, 단계별 PNG
```

## 실행

```bash
cd youtube-forms
npm install            # playwright (브라우저가 이미 있으면 npx playwright install chromium)
node record.js mdac                 # 한국어, 연습 폼
node record.js mdac --lang en       # 영어
node record.js mdac --speed 0.4     # 빠르게 (검수용)
node record.js mdac --target live   # 실제 사이트 (아래 주의 먼저 읽기)
```

결과: `out/mdac-mock-ko.mp4` (1280×720, 약 2분 40초) + 단계별 스크린샷 25장.
스크린샷은 썸네일·블로그·쇼츠 소재로 그대로 씁니다.

## 영상에 들어가는 요소

| 요소 | 위치 | 역할 |
|---|---|---|
| 인트로 카드 | 처음 4초 | "5분", 준비물 3개, 무료 강조, "화면 그대로 따라 하면 끝" |
| STEP n/22 배지 | 좌상단 | 지금 어디인지, 얼마나 남았는지 |
| 👀 보이는 대로 따라만 하세요 | 우상단 | 영상 내내 고정. "쉽다"는 인식용 |
| 빨간 테두리 + 주변 어둡게 | 현재 칸 | 어디를 입력하는지 한눈에 |
| 가짜 커서 + 클릭 링 | 현재 칸 | 클릭 위치 표시 |
| ✅ 초록 말풍선 | 칸 옆 | 입력 전: 무엇을 넣는지 |
| ⚠️ 노란 말풍선 | 칸 옆 | 입력 후: 많이 틀리는 점 + ~~틀린 예~~ 맞는 예 |
| 섹션 카드 | 중간 | "여행 정보" 같은 구간 전환 |
| 아웃로 카드 | 마지막 4.5초 | eSIM·픽업·호텔 → 설명란 링크 유도, 구독 유도 |

## 새 서식 추가하는 법

1. `forms/<id>.js`를 `forms/mdac.js` 복사해서 만듭니다.
2. `url.live`, `selectors.live`를 실제 페이지에서 확인해 채웁니다 (DevTools → 요소 검사).
3. `steps`에 칸 순서대로 `label / tip / mistake / bad / good`을 두 언어로 씁니다.
4. 연습 폼이 필요하면 `mock/<id>-form.html`을 만들고 `selectors.mock`에 id를 맞춥니다.
5. `node record.js <id> --speed 0.4`로 빠르게 검수 → 정상이면 `--speed 1`로 본 녹화.

언어 추가: `strings`와 각 step의 `text`에 `hi`, `es`, `id`, `ja` 키를 넣고 `--lang hi`로 실행.

## 실제 사이트(`--target live`)에서 녹화할 때 반드시

- **절대 제출하지 않습니다.** `stop` 단계는 버튼을 가리키기만 하고 클릭하지 않습니다. 정부 사이트에 가짜 정보를 제출하면 위법 소지가 있고 IP가 차단됩니다.
- **CAPTCHA는 자동화하지 않습니다.** `manual` 단계로 표시만 하고 넘어갑니다. 봇 탐지를 우회하는 설정(stealth 등)은 약관 위반이므로 쓰지 않습니다.
- **개인정보는 전부 가상 값**(`HONG GILDONG`, `M12345678`, `example.com`)이고 화면에 "샘플"임이 보여야 합니다. 실제 여권·이메일을 화면에 띄우지 마세요.
- `selectors.live`는 추정값입니다. 사이트는 예고 없이 바뀌므로 **녹화 전마다** 확인합니다.
- 한 번 녹화에 한 번만 접속합니다. 반복 실행은 `mock`으로 합니다.

## 알려진 한계

- Playwright 기본 녹화는 1280×720에 화질이 평범합니다. 1080p가 필요하면 `record.js`의 `size`를 1920×1080으로 올리고, 더 좋은 화질은 같은 스크립트를 `headless: false`로 띄워 OBS로 화면 녹화합니다.
- 드롭다운(`<select>`)은 브라우저 기본 UI라 펼쳐진 모습이 짧게만 보입니다. 사용자 정의 드롭다운(라이브러리)은 `type: 'click'` 단계 두 개로 나눠 처리합니다.
- 한국어·영어 외 언어는 글꼴이 설치된 환경에서 녹화해야 글자가 깨지지 않습니다.
