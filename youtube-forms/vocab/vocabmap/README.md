# VocabMap 영상 — 지도 한 장 · 20단어 · 세 번 꺼내기

vocabmap-mec.vercel.app 의 회차 데이터(손그림 지도 + 20 표제어 + 장면 글 + 이야기 빈칸)를
그대로 영상으로 옮깁니다. 지도 위에 **번호 스티커**를 붙였다가 떼는 방식이라
빈 지도 ↔ 완성 지도 사이의 그림 차이에 상관없이 깨끗하게 "채워지는" 연출이 됩니다.

```
vocabmap/
├─ map.html          # 카메라(줌·팬) + 스티커 + 카드 + 패널. window.api 로 조종
├─ record-map.js     # 영상 대본: 훅 → 장면 → 가지별 채우기+즉시 인출 → 이야기 빈칸 → 빈 지도 60초 시험
├─ data/junior-a01.js# 사이트 unit 데이터 + 지도 위 단어 좌표/각도 (손으로 측정)
└─ assets/           # junior-a01.png (완성), junior-a01-blank.png (빈 지도)
```

```bash
node record-map.js              # 1280×720, 약 5분 20초 → out/junior-a01-map.mp4
node record-map.js --speed 0.12 # 빠른 검수
```

## 영상 구조 (암기 과학 근거)

| 구간 | 길이 | 무엇을 하나 | 근거 |
|---|---|---|---|
| 훅 | 8초 | 빈 지도 → 완성 지도로 한 번에 채워지는 장면, "마지막 60초 시험" 예고 | 목표 제시 + 시험 예고가 주의 집중을 높임 |
| ① 장면 떠올리기 | 24초 | 가지별 삽화를 확대하고 한국어 장면 글. "아는 영어 단어를 먼저 말해보기" | 사전 인출(pretesting), 기존 지식 활성화 |
| ② 가지별 채우기 | 4 × 30초 | 스티커가 떼어지며 단어 등장, 카드(발음·뜻·예문·연어) | 의미망으로 묶기(정교화) + 그림과 함께 저장(이중 부호화) |
| 꺼내기 ① | 4 × 10초 | 방금 본 5개를 다시 가리고 5초 카운트다운 → 확인 | 즉시 인출 연습, 분산(가지마다 한 번) |
| 꺼내기 ② | 4 × 11초 | 20단어가 모두 들어간 이야기의 빈칸(번호 = 지도 번호) | 문맥 속 산출, 지도와 이야기의 이중 단서 |
| 꺼내기 ③ | 60초 | 빈 지도만 보고 ①~⑳ 말하기, 2.5초마다 공개 | 최종 인출 시험(testing effect) |
| 아웃로 | 7초 | "몇 개 맞혔나요? 댓글에 숫자" + D+1·D+3·D+7 복습 예고 | 간격 반복을 유튜브 업로드 일정으로 구현, 댓글 참여 |

## 다음 회차 추가

1. 사이트의 `data/unit-<id>.js`와 `img/map/<id>.png`, `<id>-blank.png`를 가져옵니다.
2. `data/junior-a01.js`를 복사해 `entries[*].pos_xy`(완성 지도 위 단어 중심 좌표)와 `angle`(단어 기울기)을 채웁니다.
   측정법: `node record-map.js --speed 0.1`로 한 번 돌려 `out/map-09-test-done.png`(전체 지도)에서 단어 위치를 읽습니다.
   화면 좌표 → 지도 좌표: `x_art = (x_screen − 158) / 0.8036`, `y_art = y_screen / 0.8036` (1200×896 지도 기준).
3. `branches[*].region.map / scene` 으로 카메라가 갈 영역을 정합니다.

## 쇼츠(복습) 버전

같은 데이터로 60초 세로 영상: 빈 지도 → 번호 순서대로 2.5초씩 공개만. `record-map.js`의 ④ 구간만 떼어
뷰포트 1080×1920으로 돌리면 됩니다(다음 작업).

## 알려진 한계

- 무음입니다. 표제어·예문은 영어 TTS(사이트의 speak.js와 같은 en-GB), 안내는 한국어로 입히세요. 대본은 데이터 파일에 다 있습니다.
