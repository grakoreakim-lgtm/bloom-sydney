맥북을 켜 두면, 맥북의 Claude가 `RUNBOOK.md`에 적힌 일을 정해진 시간에 합니다.

## 맥북이 알아서 하는 일 (승인 불필요)
- 매일: Shorts에 본편 연결, 전날 제작 결과 확인, 새 댓글 모으기
- 매주 월: 공식 사이트 서식이 바뀌었는지 확인, 주간 성과 수집
- 매주 금: 주간 보고서 작성 (`ops/reports/`)

## 승인해 주셔야 하는 일 (지금은 전부 승인 후 실행)
- 댓글 답변 게시, 제안 메일 발송, 제목·썸네일 테스트, 영상 재녹화, 새 주제 추가
- AI 시연 영상(Apps & AI 채널): ① 주제 3개 제안 → 승인 ② 맥북이 실제 앱을 써 보며 화면 녹화·편집 → 비공개 업로드 ③ 영상 확인 후 공개 승인

**승인 방법**
1. GitHub 앱 알림 "승인 대기"가 오면 목록을 봅니다. (`ops/approvals/날짜.md`에도 같은 내용이 있습니다.)
2. 맥북의 Claude 대화창에 "1, 3 승인"처럼 번호로 답합니다.
3. 승인한 것만 실행되고, 결과가 같은 파일에 기록됩니다.

## 맥북이 절대 하지 않는 일
