# 자동 운영 안내 (대표님용)

대표님 지시와 결정은 모두 `OWNER-RULES.md`에 날짜와 함께 적고, 모든 작업자가 먼저 읽습니다.
맥북을 켜 두면, 맥북의 Claude가 `RUNBOOK.md`에 적힌 일을 정해진 시간에 합니다.

## 알아서 돌아가는 일 (승인 불필요)
- **매일 밤(클라우드):** 영상 제작과 예약 업로드.
  - 한국어 채널: 본편 1개 + 쇼츠 1~2개. 영어 채널: 바뀌기 쉬운 양식(TDAC·MDAC·SGAC·VJW·ESTA)과 영어판 회화만.
  - 일본어 상황 회화(만화) 편은 순서표대로 하루 1편. 그림 검수가 끝난 편만 만듭니다.
  - 다 만든 만화 편에서 퀴즈 쇼츠("이 상황, 일본어로?")를 하루 1~2개 더 올립니다. 새 그림 없이 무료입니다.
  - 만들 것이 없는 밤은 설치·제작을 건너뛰어 시간과 돈을 아낍니다.
- **매일:** 검수(시드니 17:47), 매일 보고(09:17), 쇼츠에 본편 연결, 새 댓글 모으기와 답글 초안.
- **매주 월:** 기획(숫자 점검, 다음 회화 편, 커뮤니티 퀴즈 문구), 양식 변경 확인, 주간 성과 수집.
- **매주 금:** 주간 보고서(`ops/reports/`).
- 품질 개선, 앞으로 만들 영상의 규칙 변경, 썸네일 개선도 바로 합니다.
- 맥북: 새 영상의 끝 화면 연결(유튜브 API로는 안 되는 작업).

## 승인해 주셔야 하는 일
- 목소리 변경
- 이미 공개된 영상의 제목·공개 상태·삭제 변경
- 이메일 발송, 돈이 드는 일
- 댓글 답글 게시
- AI 시연 영상(Apps & AI 채널): ① 주제 3개 제안 → 승인 ② 녹화·편집 → 비공개 업로드 ③ 확인 후 공개 승인

**승인 방법**
1. GitHub 앱 알림 "승인 대기"가 오면 목록을 봅니다. (`ops/approvals/날짜.md`에도 같은 내용이 있습니다.)
2. "1, 3 승인"처럼 번호로 답합니다.
3. 승인한 것만 실행되고, 결과가 같은 파일에 기록됩니다.
