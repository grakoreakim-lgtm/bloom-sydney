# 대표님 지시·결정 기록 (OWNER-RULES)

모든 작업자(매일 보고, 검수, 기획, 댓글, 맥북, 새 세션)는 **작업 전에 이 파일을 먼저 읽고 따릅니다.**
대표님이 새로 지시하거나 결정하시면, 그 대화에서 바로 여기에 날짜와 함께 추가합니다. 지난 내용과 충돌하면 최신 지시가 우선이고, 바뀐 옛 줄은 지우지 말고 ~~취소선~~으로 남깁니다.

## 1. 일하는 방식
- 보고는 한국어, 쉬운 말로 짧게. 대표님이 누를 곳은 바로 가는 링크로 드린다. 대표님은 주로 휴대폰으로 본다.
- "가급적 네가 다 알아서." 대표님 손이 가는 일은 최소로. 꼭 필요한 일(결제, 휴대폰 본인 확인, PC에서만 되는 설정)만 부탁한다.
- 큰 일은 **계획 먼저 → 하나로 시험 → 확인되면 나머지 한꺼번에** (2026-11-26, 싱크 수정 때 지시).
- 매일 보고한다(시드니 09:17). 개선할 점은 스스로 조사해서 적용한다(2026-11-24).
- 요청은 더 정확한 작업 지시로 정리한 뒤 그대로 진행한다(2026-11-28).
- 비용·시간이 효율적인지 스스로 점검한다. 쓸데없는 반복 작업은 없앤다(2026-11-28).

## 2. 바로 해도 되는 일 / 승인받을 일
- **바로 해도 됨:** 매일의 품질 개선, 앞으로 만들 영상의 규칙 변경, 새 영상 제작과 예약 업로드, 썸네일 개선.
- **제안만 (승인 후 실행):**
  - 목소리 변경
  - 이미 공개된 영상의 제목·공개 상태·삭제 변경
  - 이메일 발송
  - 돈이 드는 일
  - 댓글 답글 게시 ("댓글 1,3 승인"처럼 번호로 승인)
- **예외로 승인됨:**
  - 싱크 틀린 영상의 교체(새 영상 공개 + 옛 영상 비공개, 2026-11-26 "교체 진행해")
  - 싱크 틀린 쇼츠만 교체(2026-11-27 "검사 후 어긋난 것만")
  - 일본 식당 만화판을 새 영상으로 추가 공개(2026-11-28 "1.A")

## 3. 안전 규칙 (절대)
- 비밀번호·토큰·키 값은 화면·채팅·파일·스크린샷 어디에도 남기지 않는다.
- 녹화는 가상의 예시 정보만 쓰고, 제출·결제 버튼은 절대 누르지 않는다. CAPTCHA는 풀지 않는다.
- 구글·깃허브가 휴대폰 본인 확인이나 결제 입력을 요구할 때만 대표님을 부른다.
- 유튜브 API 한도를 여러 프로젝트로 우회하지 않는다.

## 4. 영상 품질 규칙
- **나레이션과 화면은 반드시 맞아야 한다(가장 중요, 2026-11-26).**
  - 녹화 신호(모서리 마커)로 맞춘다.
  - 마커가 90% 미만으로 잡히면 QA에서 불합격시킨다.
  - 업로드 전에 sync-check 이미지로 확인한다.
- 인트로는 짧게(2문장). 끝에는 댓글·구독을 부탁한다.
- 썸네일은 v2 형식: 장소(흰색) / 무엇(노란색, 크게) / 한마디(빨간 칩). 쇼츠는 세로 화면용 썸네일.
- 설명란 링크는 누를 수 있게(구독 링크 포함). 정보는 공식 출처로만, 확인 안 된 내용은 말하지 않는다.
- "5분" 같은 시간 표현은 그대로 둔다(2026-11-27).

## 5. 목소리
- 한국어는 Gemini **Leda**를 쓴다. 한도 초과(429)면 Kore로 대체하고 이슈 #56에 기록한다. "목소리는 일단 손대지 말고 두고 보자"(2026-11-24).
- 개선 방향:
  - 대표님이 AI Studio 결제 등급을 확인해 Leda가 매번 나오게 하는 것이 1순위.
  - 엘레븐랩스는 그다음 선택지(제안만).
- 해외 노출은 유튜브 **자동 더빙**(대표님이 PC에서 켜기)으로 한다.

## 6. 회화 시리즈 (만화)
- 상황별 현지 회화 시리즈 순서: 일본 식당 → 편의점 → 교통 → 호텔(config `phraseQueue`).
- **만화 형식**(2026-11-28):
  - 4컷·8컷 만화처럼 장면 그림으로 연상 효과를 준다. 교육 전문가와 유튜브 알고리즘 관점을 반영한다(`phrases/COMIC.md`).
  - 같은 인물(지우·민준·직원)이 시리즈 내내 나온다.
  - 그림에는 글자를 넣지 않는다. 글자는 코드로 쓴다.
- 그림체: 대표님 의견 "AI 느낌이 크다 → 사람이 그린 것처럼."
  - 손그림 3안(수채 그림책 / 잉크 일기툰 / 색연필 스케치)을 제안했고, 고르신 것을 이후 모든 편에 적용한다.
  - 결정(2026-11-28): **B 잉크 일기툰.** 식당 편부터 이 그림체로 다시 그리고, 이후 모든 편에 씁니다.
- **영어판도 만든다**(2026-11-28): 같은 그림에 영어 나레이션과 로마자 발음을 넣어 영어 채널에 올린다. 한국어판과 같은 기준으로 비교한다.
- 실험: 식당 편 카드판과 만화판을 7일·14일 뒤 비교한다(`ops/experiments/comic-vs-cards.md`). 결과로 이후 형식을 정한다.

## 6b. 채널 방향 (2026-11-28, 알고리즘 진단 후 "1,2,3,4 다 진행")
1. **업로드 수를 줄인다.** 한국어 채널은 하루 본편 1개와 쇼츠 1~2개. 힌디어·스페인어·인도네시아어·일본어판은 올리지 않는다(다른 언어는 자동 더빙으로 대신). 설정: `tutorialRules`.
2. **한국어 채널의 중심은 일본어 상황 회화 시리즈.** 20~30편으로 늘리고, 몰아보기 편과 편마다 퀴즈 쇼츠를 만든다.
3. **영어 채널**은 자주 바뀌는 양식의 실제 사이트 영상(TDAC·MDAC·SGAC·VJW·ESTA)과 영어판 회화만 올린다. 2027-01-27에 다시 평가한다.
4. **"음…" 같은 일부러 넣은 망설임 소리를 뺀다**(목소리 변경 승인).
- '찍어낸 영상'으로 보이지 않게 한다: 썸네일 틀을 여러 가지로 쓰고, 화면에 확인 날짜를 넣고, 실제 질문에 답한다. 작은 수정은 재업로드하지 않는다.

## 7. 댓글·판매
- 댓글로 문의에 답하고, 맞는 경우에만 제휴 상품(offers.json)을 자연스럽게 소개한다.
- **너무 노골적이면 안 되고, 같은 패턴의 답글을 반복하지 않는다**(2026-11-26). 상세: `ops/roles/comments.md` 3b.
- 게시는 항상 대표님 승인 후에 한다. 지금 토큰은 답글 권한(force-ssl)이 없어 재발급이 필요하다.

## 8. 역할

- 나머지(편집·썸네일·분석)는 매일 공정과 매일 보고에서 처리한다.
