follow-done 개인정보처리방침 / Privacy Policy

시행일 / Effective: 2026-11-20

1. 수집하는 정보

follow-done은 운영자 본인의 Google 계정으로만 YouTube Data API에 접근합니다. 일반 사용자의 개인정보는 수집하지 않습니다. 운영자 계정의 OAuth 토큰은 영상 업로드에만 쓰이며, 암호화된 비밀 저장소(GitHub Actions Secrets)에만 보관됩니다.

2. Google 사용자 데이터의 사용

요청 범위(youtube.upload, youtube)는 운영자 채널에 영상을 올리고 제목·설명·재생목록을 관리하는 데만 사용합니다. 데이터를 판매하거나 제3자와 공유하지 않으며, 광고 목적으로 사용하지 않습니다. follow-done의 Google API 데이터 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

3. YouTube API 서비스

follow-done은 YouTube API 서비스를 사용합니다. 이용 시 YouTube 서비스 약관과 Google 개인정보처리방침이 적용됩니다. 접근 권한은 언제든 Google 계정 보안 설정에서 해제할 수 있습니다.

4. 보관과 삭제

토큰은 운영자가 권한을 해제하거나 비밀값을 삭제하면 즉시 무효가 됩니다. 별도의 사용자 데이터베이스는 운영하지 않습니다.

English summary

follow-done accesses the YouTube Data API only with its operator's own Google account to upload videos to channels the operator owns. It does not collect personal data from other users, does not sell or share Google user data, and complies with the Google API Services User Data Policy, including the Limited Use requirements. Use of YouTube API Services is subject to the YouTube Terms of Service and the Google Privacy Policy. Access can be revoked at any time at Google Account permissions.
